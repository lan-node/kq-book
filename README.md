# 出工记账本（kq-book）

工地日结工的考勤 + 工资记账本。一个月是一盒磁带：红条标月份导航，白卡纸上一支圆珠笔、一支红笔，卡头手写总额就是实发。

**在线使用**：https://lan-node.github.io/kq-book/

## 功能

- **A 面 · 出工单**：逐日出工/半天/歇班 + 加班点数 + 备注；手写总额 = 出勤×日薪 + 加班×时薪 − 当月借支
- **B 面 · 账目**：月历四态格（出工实心蓝 / 半天 ½ / 歇班虚线 / 加班红点）、每周汇总、按月统计、年度累计
- **卡背**：借支登记（金额 + 备注 + 归属日期）、工资单价设置、数据导出/导入/清空
- **同步**：
  - **GitHub 云同步**（推荐）：卡背粘贴 GitHub Token → 创建云端账本 → 每台设备填同一 Token + 账本 ID，任何网络自动互通
  - **局域网同步**：同一 WiFi 下运行 `server.mjs`（或双击 `启动同步服务.bat`），15 秒自动互推
- 数据存浏览器本地（localStorage），云端走隐藏 Gist，不进仓库

## 电脑本地运行

双击 `index.html` 即可（离线可用）。要与手机在同一 WiFi 下同步，双击 `启动同步服务.bat`（需 Node.js）。

## 技术设计

单文件 HTML/CSS/vanilla JS，无构建、无依赖、离线优先。设计系统见 [DESIGN.md](DESIGN.md)（方向：`vernacular-ephemera-cassette-jcard` 磁带 J 卡 + 圆珠笔账）。

## 重置数据

卡背 → 数据 → 备份全部（导出 JSON）。换手机：新设备导入备份，或配好云同步自动拉取。
